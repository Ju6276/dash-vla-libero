# 新指令上的 AEGIS-SFT（2026-11-01）

## 目的

检查这个前提：VLA 没学过的指令，"VLA + CBF"（AEGIS）做不成。如果成立，规划器就有了存在的理由，文章改为在新指令上比较。

## 设置

- **新指令**：6 条，都在 SafeLIBERO task 0 的场景里，只改语言指令和成功条件。物体、障碍物、初始状态和碰撞判定都和原来一样。逐条对照过 LIBERO-130 的 140 条指令（SFT 数据），都不在里面。脚本：`scripts/safelibero/make_new_instructions.py`。
- **回合**：每条指令 × 等级 I、II × episode 0–3，共 48 个回合，上限 900 步。
- **对象**：AEGIS + SFT 版 VLA（`run_aegis.py --variants`）。障碍物仍由 Codex sol 命名。
- **注意**：障碍物原本是按 task 0 的路线摆的，换了指令后，路线上不一定有障碍物。

## 结果

| 新指令 | 场景 | 成功（I / II） | 碰撞（I / II） |
|---|---|---|---|
| 把盘子和小碗之间的黑碗放到炉子上 | spatial | 1/4 · 0/4 | 1 · 3 |
| 把盘子和小碗之间的黑碗放到木柜顶上 | spatial | 3/4 · 0/4 | 0 · 4 |
| 把奶油奶酪放到盘子上 | goal | 0/4 · 0/4 | 2 · 1 |
| 把碗放到炉子上，再把奶油奶酪放到盘子上 | goal | 0/4 · 0/4 | 0 · 0 |
| 把黄油和番茄酱都放进篮子 | object | 0/4 · 2/4 | 2 · 0 |
| 把番茄酱和番茄酱汁都放进篮子 | long_I 场景 | 0/4 · 0/4 | 3 · 0 |
| **合计** | | **7/48（15%）** | **20/48** |

- 成功的 7 个回合都没有碰撞，SSR 是 7/48。
- task 0 上，同一个 AEGIS-SFT 的 SSR 是 14/16。
- 没成功的回合都跑满了 900 步。

## 判断

- 按事先定的标准（成功率低于 30% 就算前提成立），**前提成立**。VLA 加上 CBF，在没学过的指令上基本做不成任务。
- **CBF 还挡不住碰撞**：48 个回合里撞了 20 个，比 task 0（1/16）多得多。VLA 在新指令上会四处乱动，夹爪以外的手臂部分更容易碰上障碍物（参见报告 13）。
- **下一步**：在同样的回合上跑原版 Harness（B0）、SafeHarness（B2）和我们的方法。Harness 还需要支持加载这些新任务；这些规划器类的运行要用 Codex 额度。
